# VANGUARD - Calculadora de ROI — Design System

## Brand
- **Name**: VANGUARD COMPANY — Segurança Eletrônica
- **Logo**: Stylized "V" in neon green
- **Vibe**: High-tech dark security monitoring panel

## Colors
- **Background**: #000000 (pure black)
- **Neon Green (primary)**: #39FF14
- **Silver/Metallic**: #A8A9AD / #C0C0C0
- **Dark surface cards**: #0A0A0A / #111111
- **Input borders**: #1A1A1A with green glow on focus
- **Text**: white #FFFFFF, silver #A8A9AD for secondary

## Typography
- **Display/ROAS**: Orbitron (digital/futuristic)
- **Body**: Rajdhani or Exo 2 (techy, clean)
- **Hierarchy**: ROAS number massive, labels in silver uppercase

## Layout
- Single page, centered, max-w ~500px
- Logo "V" + "VANGUARD COMPANY" top
- Inputs stacked with green glow borders
- Results in prominent cards below
- Sticky CTA footer

## Effects
- Green neon glow: `0 0 10px #39FF14, 0 0 20px #39FF1480`
- Input focus glow animation
- ROAS card with pulsing border glow
- Scanline or grid subtle background pattern
- Smooth number transitions on calculation

## Components
- Input fields: dark bg, rounded-xl, green glow border on focus
- Result cards: dark surface, green accent borders
- ROAS highlight: large digital font, green if positive, silver if low
- CTA buttons: solid green bg, black text, or outlined green
